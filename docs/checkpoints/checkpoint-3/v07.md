## Implementation Summary

1. **Isolation Enforcer (`src/recycleguard/isolation.py`):**
   - `RuntimeIsolationEnforcer`: Restricts filesystem access to visible input and dedicated writable runtime mounts.
   - Enforces pattern and path blocking against `benchmarks/evaluation`, `tests/fixtures/expected`, `.git`, `.env*`, and ground-truth/oracle terms.

   - Sanitizes runtime environment by stripping answer-bearing variables (`ORACLE_*`, `GROUND_TRUTH_*`, `BENCHMARK_SEED_*`).
   - Validates candidate mount lists and generates `IsolationReport`.
   - Records every attempted forbidden access as an `IsolationViolation` with action `DENIED_AND_RECORDED`.
