## Implementation Summary

1. **Boundary Models (`src/recycleguard/contracts/bundles.py`):**
   - `BundleManifest`: Authoritative manifest with `included_objects_blob`, `omission_dispositions_blob`, `attribution_blob`, `audit_head_refs`, and `completeness`.
   - `IntegrityResult`: Object-level SHA-256 validation, byte length verification, and audit hash-chain continuity.
   - `ReplayRequest` & `ReplayResult`: Offline replay specification and outcome models.
   - `RightsDecision`, `OmissionDisposition`, `AttributionRecord`, `IncludedObjectEntry`.

2. **C14 Export, Integrity and Replay Service (`src/recycleguard/exports/service.py`):**
   - `export_bundle`: Exports `COMPLETE_LOCAL` bundles with all run and case assets, or `QUALIFIED_PUBLIC` bundles enforcing recursive rights-through-derivatives inspection.
   - Rights-through-derivatives check: Excludes restricted raw sources and recursively withholds derived provisions, prompt contexts, and model input excerpts, producing explicit `OmissionDisposition` records.
   - `verify_bundle`: Computes and verifies exact SHA-256 digests and audit hash-chain sequences, returning `PASS` or `FAIL`.
   - `replay_bundle`: Executes strictly offline `ARTIFACT` replay without external model provider or network calls.

3. **CLI Integration (`src/recycleguard/cli.py`):**
   - `recycleguard audit export --run-id <run-id> --kind <kind>`
   - `recycleguard audit verify --bundle-id <bundle-id>`
   - `recycleguard replay --bundle-id <bundle-id> --mode ARTIFACT`

4. **Automated Test Coverage:**
   - `tests/test_v06_export_replay.py`: Complete local export, rights-through-derivatives inspection, tampered bundle detection, and offline no-provider replay.
   - `tests/acceptance/test_review_export.py`: G10 acceptance test covering review decisions, stale digest rejection, and public export omissions.
