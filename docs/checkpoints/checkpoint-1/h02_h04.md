## 1. Scope and delivered capabilities

### H02: Acquisition and full-batch intake (`recycleguard.intake`)
- **Full-batch directory discovery**: Scans submitted batch boundaries, recursively inspecting `records/`, `documents/`, and root directories.
- **CP1 complete inventory accounting**:
  - Valid declared assets verified with SHA-256 and byte length (`intake_status="RECEIVED"`).
  - Duplicate files across different paths receive distinct receipts referencing the content-addressed blob.
  - Undeclared extra files receive `RECEIVED` receipts with `declared_asset_id=None` and explanatory note.
  - Declared assets missing from disk receive `DECLARED_MISSING` receipts without an invented blob or hash.
  - Corrupt documents receive `RECEIVED` receipts with `HASH_MISMATCH` issues, preserving raw bytes for downstream extraction analysis.
  - Symlinks and path traversals outside the batch boundary are rejected with `REJECTED_ACCESS` receipts.
- **Acquisition attempts**: `record_acquisition` records URL, fetch attempts, and logs `FETCH_FAILED` receipts on errors without inventing blobs.
- **Audited persistence**: Executes within an audited transaction using `AuditKernel` under `intake.` permission prefix, persisting revisions and receipts to `ArtifactCatalog`.

### H03: Extraction and page/row coverage (`recycleguard.extraction`)
- **CSV row extractor (`extract_csv`)**:
  - Enforces 1-based data row locators (`kind="CSV_ROW"`).
  - Terminal row dispositions (`PARSED`, `QUARANTINED`, `FAILED`) strictly sum to discovered rows.
  - Verified by `validate_row_coverage_consistency`.
  - Emits `Observation` records with raw fields, parsed numbers/dates, and temporal triad.
- **JSON / JSONL extractor (`extract_json`)**:
  - Handles line-by-line JSONL streams and single JSON objects/arrays.
  - Emits observations and coverage items with `JSON_POINTER` locators.
- **PDF page-level extractor (`extract_pdf_pages`)**:
  - Genuinely reads physical PDF pages using `pdfplumber` / `pypdfium2` / `pdfminer`.
  - Physical 1-based page index matches coverage item count.
  - Text-bearing pages receive `PARSED` disposition; blank/unsupported scans receive `QUARANTINED` with explicit `UNSUPPORTED_SCAN_OR_EMPTY_PAGE` issue.
- **Unified ExtractionService (`extract_artifact`)**:
  - Retrieves blob from `BlobStore`, executes extractor, persists `observations_blob`, `coverage_blob`, and `text_blob`, and returns validated `ExtractionResult` matching CONTRACTS §3.3.
