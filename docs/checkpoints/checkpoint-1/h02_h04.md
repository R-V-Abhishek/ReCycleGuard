## H03: extraction

and issue records. CSV cells preserve string precision and leading-zero identifiers.
PDF parsing uses the installed pdfplumber parser explicitly; corrupt files fail
with an issue and unsupported scans remain quarantined. The parser is a locked
runtime dependency. No Chandra/Paddle weights, OCR backend or inference dependency
was selected or installed.

The A04 coordinator archives complete extraction outputs and coverage before
normalization, so unsupported content is accounted for rather than silently lost.
